# SentiNet: IoT Security Monitoring System

## Overview

SentiNet is a web-based IoT Security Monitoring System designed to help Small and Medium Enterprises (SMEs) identify, assess, and manage security risks associated with Internet of Things (IoT) devices.

The system provides network discovery, device identification, vulnerability assessment, security policy compliance checks, risk scoring, and centralized monitoring through an interactive dashboard.

---

## Problem Statement

The increasing adoption of IoT devices has expanded organizational attack surfaces, while many SMEs lack affordable tools to continuously monitor connected devices and identify security weaknesses.

SentiNet addresses this challenge by providing visibility into network-connected IoT devices and helping organizations identify and prioritize security risks.

---

## Objectives

- Discover devices connected to a network.
- Identify and classify IoT devices.
- Assess device vulnerabilities using CVE data.
- Perform security policy compliance checks.
- Generate risk scores and security recommendations.
- Provide centralized security monitoring and reporting.

---

## Key Features

- Network Discovery using Nmap
- IoT Device Classification
- Vulnerability Assessment using NVD/CVE Intelligence
- Security Policy Compliance Checks
- Risk Scoring and Prioritization
- Centralized Dashboard
- Security Recommendations
- Reporting and Analytics
